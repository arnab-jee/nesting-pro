# Update 002

## Objective

- Update the grain logic if incorrectly applied.

## Logic

The parameter `Grain` can be either $0$, $1$ or $2$.

### Condition [ $\text{grain} = 0$ ]

Parts can be placed any way regardless of the grain direction.


### Condition [ $\text{grain} = 1$ ]

Parts must be placed as such that it's length is parallel to the grain direction.


### Condition [ $\text{grain} = 2$ ]

Parts must be placed as such that it's length is perpendicular to the grain direction.
